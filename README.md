Tema escolhido
Jogo da Forca (Hangman) com interface gráfica, desenvolvido em Python usando a biblioteca Pygame.

Objetivo do sistema
O sistema tem como objetivo proporcionar um jogo de adivinhação de palavras, onde o jogador tenta descobrir uma palavra secreta, letra por letra, dentro de um número limitado de tentativas erradas, exercitando lógica e vocabulário.

Breve descrição do funcionamento
Ao iniciar o jogo, uma palavra é sorteada aleatoriamente de uma lista pré-definida e fica escondida na tela, mostrando apenas espaços em branco correspondentes ao número de letras. O jogador escolhe letras clicando em um teclado virtual exibido na janela do jogo (ou digitando pelo teclado do computador). A cada letra correta, ela é revelada na posição certa da palavra. A cada letra errada, uma nova parte do desenho da forca é adicionada (poste, corda, cabeça, corpo, braços, pernas), e o jogador perde uma tentativa. O jogo termina em vitória, se o jogador completar a palavra antes de errar 6 vezes, ou em derrota, se errar todas as tentativas antes de completar a palavra — sendo exibida uma tela final com a opção de jogar novamente.
